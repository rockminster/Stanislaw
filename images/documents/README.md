# Document Images

This directory will contain scanned images of historical documents related to Stanislaw Rockminster.

## Document Types

This directory should include:
- Service records
- Photographs
- Letters and correspondence
- Certificates and qualifications
- Commendations and awards
- Any other relevant historical documents

## File Naming Convention

Use descriptive names for documents:
- `service_record_1940.jpg`
- `squadron_photo_1943.jpg`
- `commendation_letter_date.jpg`
- etc.

## Image Format

- Preferred format: JPEG or PNG
- Recommended resolution: 300 DPI for documents, 200+ DPI for photographs
- Recommended dimensions: Appropriate to maintain readability

## Usage

These images will be displayed in the Documents section of the website. To add a new document:

1. Place the image file in this directory
2. Update the `documentsData` array in `script.js` to reference the image
3. Add descriptive information about the document
