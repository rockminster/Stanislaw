# Logbook Images

This directory will contain scanned images of Stanislaw Rockminster's RAF logbook pages.

## File Naming Convention

Use the following naming convention for logbook images:
- `logbook_page_001.jpg` - First page of logbook
- `logbook_page_002.jpg` - Second page of logbook
- etc.

## Image Format

- Preferred format: JPEG or PNG
- Recommended resolution: 300 DPI for clear readability
- Recommended dimensions: At least 1200px wide

## Usage

These images will be displayed in the Logbook section of the website. To add a new logbook page:

1. Place the image file in this directory
2. Update the `logbookData` array in `script.js` to reference the image
3. Add enriched data about the flights recorded on that page
